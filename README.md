# KeyLimiter [BETA]

> ### ⚠️ 사용 전 주의사항
> 이 모드는 현재 정식 출시 예정인 모드입니다. 사용 시 발생하는 문제의 책임은 본인에게 있습니다. AI의 비중이 높은 프로젝트입니다. 정식 출시 전 AI의 의존도를 전부 걷어낼 예정입니다.


얼불춤(A Dance of Fire and Ice) 레벨 에디터에 **키 제한** 이벤트를 추가하는 Unity Mod Manager 모드입니다. 이벤트 이후 사용할 수 있는 서로 다른 입력 키의 수를 제한합니다.

## 설치 및 사용

1. 게임에 Unity Mod Manager를 설치합니다.
2. 빌드한 `KeyLimiter.zip`을 Unity Mod Manager로 설치하고 KeyLimiter를 활성화합니다.
3. 레벨 에디터에서 타일을 선택한 다음 **이벤트 조절 → 키 제한** 이벤트를 추가합니다.
4. **키 제한 수**와 **제한 초과 시 동작**을 설정하고 레벨을 저장합니다.

| 설정 | 동작 |
| --- | --- |
| 키 제한 수 `0` | 제한 해제 |
| 키 제한 수 `1`~`100` | 해당 수만큼 서로 다른 입력 키 사용 가능; 기본값 `1` |
| 제한 초과 시 동작: 사망 | 새로운 키가 제한을 초과하면 사망; 기본값 |
| 제한 초과 시 동작: 입력 무시 | 제한을 초과하는 입력 무시 |

예를 들어 제한이 `4`이면 `A`, `S`, `D`, `F`를 등록한 후 이 네 키를 반복해서 사용할 수 있습니다. 이후 `G`처럼 등록되지 않은 키를 누르면 설정한 초과 동작이 적용됩니다. 게임이 유효한 플레이 입력으로 집계한 키를 기준으로 계산하며, 여러 새 키를 동시에 입력해 한도를 넘으면 해당 입력 묶음이 거부됩니다.

제한은 다음 키 제한 이벤트까지 유지됩니다. 새 이벤트가 적용되면 사용한 키 기록을 초기화하므로, 같은 제한 수를 가진 이벤트로도 키 조합을 다시 등록할 수 있습니다. UI는 한국어와 영어를 지원하며 다른 언어에서는 영어로 표시합니다. 이 이벤트를 포함한 레벨을 플레이하려면 모드가 필요합니다.

## 제한 이미지

제한 이벤트가 발동하면 `decorations/<제한 수>.png`를 표시합니다. 기본 배포 이미지는 `1.png`부터 `24.png`까지이며, `0` 또는 `25` 이상의 제한에는 이미지가 표시되지 않습니다.

설치된 모드 폴더의 `icon.png`를 바꾸면 에디터 이벤트 아이콘을, `decorations/1.png`~`24.png`를 바꾸면 각 제한 팝업을 변경할 수 있습니다. 이미지를 교체한 후에는 게임을 다시 시작해 캐시를 갱신합니다.
