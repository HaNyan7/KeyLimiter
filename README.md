# KeyLimiter [BETA]

> [!WARNING]
> 이 모드는 현재 정식 출시 예정인 모드입니다. 사용 시 발생하는 문제의 책임은 본인에게 있습니다.

얼불춤(A Dance of Fire and Ice) 플레이 중 간단한 HUD 텍스트를 표시하는 Unity Mod Manager 모드입니다.

## 설치 및 사용

1. 게임에 Unity Mod Manager를 설치합니다.
2. 빌드한 `KeyLimiter.zip`을 Unity Mod Manager로 설치하고 KeyLimiter를 활성화합니다.
3. Unity Mod Manager 설정에서 **HUD 표시**를 켠 후 레벨을 플레이합니다.
4. 플레이 중 화면 왼쪽 위에 `HUD` 텍스트가 표시됩니다.

## 모드 설정

**HUD 표시** 설정으로 플레이 중 텍스트 표시 여부를 변경할 수 있습니다. 설정 UI는 한국어와 영어를 지원하며 다른 언어에서는 영어로 표시합니다.
