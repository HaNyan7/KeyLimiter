# Why Not Support Editor Setting
## English
This mod can be used regardless of the settings of existing levels. In other words, levels do not depend on this mod.

If you want to set different key limits for individual levels or use key restrictions as intended by the level creator, please use the PACL2 mod instead.
## Korean
이 모드는 기존 맵의 설정과 상관없이 사용이 가능합니다. 즉 레벨에서 모드를 의존하지 않습니다.

레벨의 키 제한 수 가변 설정이나 레벨 제작자의 의도에 맞게 사용을 하시고 싶으시다면 PACL2모드를 사용해주세요.
